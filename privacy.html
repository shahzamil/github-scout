Privacy Policy

GitHub Scout is an independent technical recruiting research tool. This policy explains what information is collected when you visit the website, create an account, or save work.

GitHub access tokens are never uploaded to GitHub Scout or stored in its database. They remain in your browser and are sent only to GitHub when you use GitHub features.

Information we collect

When you create an account, we may collect your verified email address, name, company, authentication provider, registration date and recent account activity. Google sign-in provides only basic identity information that you approve, such as your name, email address and profile image.

When you choose to save recruiting work, we store the projects, job descriptions, GitHub candidate references, scores, stages, notes and summaries that you intentionally save to your account.

We also collect limited usage information, including an anonymous visitor and session identifier, visit time, page path, referral hostname, device category, browser, operating system, language, time zone, screen size and feature events such as a scan or search being started.

Information analytics does not collect

  • GitHub access-token values
  • Passwords
  • Candidate search queries or filters
  • Pasted LinkedIn profile text
  • Unsaved job descriptions, reports or shortlist notes

How information is used

We use information to authenticate users, synchronize private recruiting work, operate and secure the service, understand product usage, diagnose problems and improve GitHub Scout. We do not sell personal information.

Storage and service providers

Account and saved-work data is processed through Supabase. The website is hosted on Vercel. GitHub data is requested from GitHub's APIs when you use the product. Google processes authentication when you choose Google sign-in. Each provider processes data under its own terms and privacy policy.

Local browser storage

GitHub Scout uses browser storage for sessions, preferences, local shortlist data and an anonymous visitor identifier. If you explicitly choose “remember on this device,” your GitHub token is stored only in that browser. Use this option only on a device you trust.

Access and security

Row Level Security restricts account holders to their own projects and saved candidate records. The GitHub Scout owner can access account and usage records for administration, security and support. No internet service can guarantee absolute security, so avoid storing unnecessary sensitive information in notes or job descriptions.

Retention and deletion

Account and saved-work data is retained while the account is active or as reasonably necessary to operate and secure the service. You may request correction or deletion of your account and associated data by contacting us.

Public GitHub information

GitHub Scout analyzes public GitHub information as supporting recruiting context. Public activity is incomplete and must not be treated as a final hiring decision. GitHub Scout is independent and is not affiliated with or endorsed by GitHub.
